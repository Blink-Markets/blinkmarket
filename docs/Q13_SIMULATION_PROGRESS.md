# Q13 attack simulation progress

This record tracks the Q13 attack simulation of Mechanism R, task by task. The plan is [2026-11-27-q13-attack-simulation.md](superpowers/plans/2026-11-27-q13-attack-simulation.md). The simulation decides whether Mechanism R, the sponsor-funded forecast bounty, can be exploited for profit beyond its published costs. It also proposes the parameters the spec leaves to "set by simulation", recomputes the sponsor cost under burning, and measures seven open questions. The user then decides, from the result, whether Mechanism R enters the next contract generation. The design it checks is [the next-generation spec](superpowers/specs/2026-11-23-next-generation-design.md), section 9.7.

Each task's section is filled at that task's checkpoint, in checkpoint order: the scope that landed, the real verification output, any verification limit and the review result. Implementers do not edit this file.
