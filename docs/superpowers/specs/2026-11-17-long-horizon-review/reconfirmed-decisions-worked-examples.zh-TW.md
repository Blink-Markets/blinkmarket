# 暫定決策的實例確認

[English](reconfirmed-decisions-worked-examples.md)

2026-11-18 在決策板上選定的 21 張卡，大多是照助理的建議選的；紀錄 12.5 把它們列為暫定方向，等每個機制用實例講清楚後再確認。這份文件逐輪收錄這些實例：每一節是使用者做選擇前看到的例子、建議和代價，結果記在[討論紀錄](../2026-11-16-long-horizon-forecasting-discussion.md) 12.8 以後的章節。數字由 [`scripts/reconfirmed_examples.py`](scripts/reconfirmed_examples.py) 算出，名詞沿用[機制 R 的實例](mechanism-r-worked-example.zh-TW.md)。以下都還沒有實作。

## 第 1 輪，2026-11-22：Q9 與 Q16

### 兩個名詞

- **信用**：預測者在已結算題目上的成績紀錄，用來決定他的預測算不算進網站上的數字。
- **相對分數**：結算後，用基準線的誤差減掉預測者的誤差。誤差 = (預測 − 結果)²，結果「是」記 1，「否」記 0。

### Q9：信用只當及格門檻，只在有人出錢的題目上計算

**為什麼信用不能當權重。** 基準線 50%，預測者報 55%，而真實機率剛好是 55%：

| 結果 | 基準線的誤差 | 預測者的誤差 | 相對分數 |
| --- | --- | --- | --- |
| 是（機率 55%） | 0.25 | 0.2025 | +0.0475 |
| 否（機率 45%） | 0.25 | 0.3025 | −0.0525 |

平均每題 +0.0025，每題的起伏（標準差）約 0.05，是平均值的 20 倍。答完 50 題，累計分數為正的機率約 61%（審查報告的 67% 是另一組設定下的模擬）；答到約 1,600 題，平均值才達到兩個標準誤，這時累計分數為正的機率約 98%。以現在的資料量，拿信用當權重等於放大運氣。

**信用拿什麼來比。**

| 拿什麼來比 | 壞情況 |
| --- | --- |
| 絕對誤差（現在的程式） | 專挑幾乎確定的題目答 99%，誤差很小、信用很高，再拿這份信用去影響難題 |
| 上一個視窗免費預測的平均 | 假帳號把平均拖到 1%，主帳號報 50%；真實機率 50% 時，每題平均拿 0.2401，是誠實 5 點優勢（0.0025）的 96 倍 |
| 付費基準線，只算押了錢的預測 | 免費帳號推不動付費基準線，要推就得花錢 |

```
有人出錢的題目
  押了錢的預測
    │ 結算後，跟付費基準線比
    ▼
  信用（每題最多算一筆）
    │ 只看及格或不及格
    ▼
沒人出錢的題目
  網站上的數字 = 及格者的預測，彼此平等（例如取中位數）
  在這裡預測：拿不到錢，也拿不到信用
```

**決定（使用者回「是」）**：明顯比基準線差的預測者排除，其他及格的人一律平等（例如取中位數）。信用只來自有人出錢的題目上押了錢的預測，每題最多算一筆。

**選擇前已說明的代價**：

1. 信用分不出「好」和「很好」的預測者。這等於承認，以現在的資料量做不到這件事。
2. 沒人出錢的題目，預測既拿不到錢，也拿不到信用。這些題目上誰來預測，只能靠自願的 agent；要不要給它們誘因，是另一個題目。
3. 及格資格還是買得到。一群假帳號先在有人出錢的題目上照抄基準線，相對分數是 0，不會被排除；接著到沒人出錢的題目上一起報極端值，人數過半就拿下中位數。每個帳號約 10 bUSD 註冊費，另加 100 bUSD 可退押金。任何信用公式都擋不住，只能清楚標示（Q10）。

### Q16：拿掉「建立者預設出賞金、從手續費收回」

| 項目 | 數字 |
| --- | --- |
| 手續費 | taker 付款的 1%，建立者分 25% |
| 每題成交上限 | 10,000 對，每對 taker 最多付 1 bUSD |
| 建立者最多收回 | 10,000 × 1 × 1% × 25% = 25 bUSD；價格在 50% 附近約 12.5 bUSD |
| 建立一題的保證金 | 500 bUSD |
| 12.5 bUSD 託管撐得起的額度 | 50（託管 = 0.25 × 第一個視窗的額度） |
| 準 10 個百分點、獨拿整個額度的預測者，一個視窗的期望收入 | 50 × 0.1² = 0.50，低於一次推論的假設成本 1.00 |

**決定（使用者回「是」）**：建立者想出錢，就跟任何出資者一樣，在第一個視窗開始前存好全部託管。

**選擇前已說明的代價**：沒人出錢的題目一律沒有賞金，這類題目可能很多。主網若把每題成交上限提高 100 倍，可收回上限變成 1,250 到 2,500 bUSD，到時重新檢討。

## 第 2 輪，2026-11-22：沒人出錢的題目上的 Q10，以及 Q20

### 兩個名詞

- **分桶**：信用按題目長短分開記，例如幾週內結算的短期題和要等幾個月到幾年的長期題，各記各的。擅長短期題，不代表擅長長期題。
- **子市場**：掛在長期題底下的短期題。例如母題「2028 年選舉誰贏」底下，可以開一個子市場「某家民調 11 月的平均是否超過 45%」。

### Q10：沒人出錢的題目，網站上顯示什麼

一題沒人出錢的題目收到 7 個預測。三個認真的 agent 報 62%、58%、60%；另外有人開了 4 個新帳號，各報 5%。開這 4 個帳號要花 40 bUSD 註冊費，另押 400 bUSD（之後可以拿回）。

| 顯示方式 | 網站上的數字 |
| --- | --- |
| 全部平均（現在的程式） | (62 + 58 + 60 + 4 × 5) ÷ 7 = 28.6% |
| 全部取中位數 | 5%（7 個裡有 4 個是 5%） |
| 只算及格者（三個 agent 有信用，新帳號沒有） | 60%，標示「無質押」 |
| 沒有人及格（冷啟動時很常見） | 不顯示數字，只列出 7 個預測 |

也就是說，只要花 40 bUSD，就能把「全部平均」從 60% 拖到 28.6%。

**決定（使用者回「是」）**：有人及格時，顯示及格者的中位數，並標示「無質押」，意思是這個數字背後沒有人押錢；沒有人及格時不顯示數字，只列出各個預測。這樣網站上不會出現「看起來可信、其實花 40 bUSD 就能拖動」的數字。「無質押」的標示要保留，因為照第 1 輪 Q9 的代價 3，及格資格也買得到，只是比較慢。

**選擇前已說明的代價**：冷啟動期間，大多數沒人出錢的題目沒有數字，只有一串預測，知識庫剛開始會顯得很空。另一個選項是每題都顯示全部平均，旁邊清楚標示「沒押錢、沒加權，可被假帳號拖動」；如果認為「每題都要有一個數字」比「數字不能被便宜買到」重要，就該選它。

### Q20：長期題不借用短期題的信用

建立者 C 跟某家民調機構有關係，事先知道它每月的數字。

1. C 開子市場「這家民調 11 月的平均是否超過 45%」，自己出一筆小賞金，起始機率設 50%，再用自己的幾個帳號押正確答案。結算後這些帳號的相對分數都是正的，在短期桶及格。C 幾乎只付了註冊費：帳號領到的賞金和繳的入場費，都是在 C 自己的帳戶之間移動。賞金遠大於入場費，所以池子剩下的錢少於 C 存入的託管，結算後全數回到身為出資者的 C 手上，沒有東西被銷毀。
2. 如果有借用規則：母題「2028 年選舉誰贏」是長期題，長期桶還沒有人有信用，就改用短期桶。C 的帳號於是成了母題上的「及格者」，可以左右母題顯示的中位數。
3. 拿掉借用規則：C 在短期題拿到的信用，在母題上不算，這條路就斷了。

**決定（使用者回「是」）**：長期題只認長期題賺到的信用，拿掉「長期桶沒人及格時，借用短期桶信用」這條規則。子市場照樣可以開，照樣有價格和結算結果給人看，只是不再透過任何途徑影響母題的數字。紀錄 12.7 節使用者同意的 Q2 改寫，已經是這樣寫的。

**選擇前已說明的代價**：長期題要等其他長期題陸續結算、有人累積出長期信用，才會有及格者。在那之前，可能長達好幾年，沒人出錢的長期題都沒有數字（因為 Q10 選了「是」）。有人出錢的長期題不受影響，它們顯示的是付費基準線。
